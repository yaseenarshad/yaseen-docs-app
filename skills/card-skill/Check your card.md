# Check your card

Go through this list before you add a card.

## The checks the app makes

The app finds these mistakes by itself. `yaseendocs card check <page.md>` lists them, and the card shows them in the app. Fix each one.

1. **A `{{` has no closing `}}`.** Nothing is hidden on that side.
2. **A hidden word is empty.** `{{}}` hides nothing.
3. **Nothing is hidden, and the card has no back.** A card with one side needs at least one hidden word.
4. **The card has no title.** A card in a page has no first line with text. A card file has no `title:` and no first line.
5. **The title is still "Title".** Give it a real name, in the first line or in `title:`.
6. **The question hides its own subject.** "What does {{…}} stand for" or "What does {{…}} mean" cannot be answered.

The app does not check text inside code spans or code blocks. It does not check length: a long card is fine when it holds one idea.

## The checks only you can make

- [ ] The card has one recall task, and its format fits that task.
- [ ] With the answers hidden, the front makes sense to someone who does not know them.
- [ ] The hidden words are the answer, not the clues.
- [ ] No nearby answer fits the clue as well as the right one.
- [ ] The front does not give the answer away in another word, and neither does the start of the back.
- [ ] The title names the general idea, and it is shown or hidden as [[Titles]] says.
- [ ] The text reads well in one pass, with no filler.
- [ ] With the answers shown, the grammar is right and the facts are true.
- [ ] `***` divides sections on one side. `---` only starts a new side.
- [ ] Each link says what the other card adds.
- [ ] Each picture has alt text and teaches one point.
- [ ] In an edit, only the part you were asked to change has changed.
