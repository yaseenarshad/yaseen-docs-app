# Acronym

Use it when the learner must recall what the letters stand for. To learn what the thing is, use [[concept]]. **Title: shown.** The acronym is the cue. The expansion is the answer.

## Skeleton

- Title: the acronym.
- Front: "What does X stand for?", with the field named when the letters mean more than one thing.
- Back: the expansion, hidden as one phrase, not word by word. Then one plain sentence on what it is.

## Example

```markdown
HTTP

What does HTTP stand for on the web?
---
HTTP stands for {{Hypertext Transfer Protocol}}.

It is the set of rules a browser and a web server use to send pages to each other.
```
