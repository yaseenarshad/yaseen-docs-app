# Quote

Use it to recall a particular line, word for word, and when to use it. **Title: hidden.** The title names the speaker and the topic.

## Skeleton

- Title: `<Speaker> on <topic>`, hidden. Use a theme when the speaker is not certain.
- Front: a situation where the quote would help. Then the exact quote, with a few key words hidden.
- Back: what it means, or when to use it. The source, if it is verified.

## Example

```markdown
{{Roosevelt on fear}}

A team panics about a problem more than the problem calls for. Which line fits?

"The only thing we have to fear is {{fear itself}}."
---
Franklin D. Roosevelt, first inaugural address, March 1933.

Panic can do more harm than the danger that caused it.
```
