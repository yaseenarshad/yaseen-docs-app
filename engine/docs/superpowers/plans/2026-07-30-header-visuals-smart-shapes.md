# Header, Visual Insertion, and Smart Shapes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Simplify the editor header, consolidate view-only sharing into the purple Share control, make Image Studio inserts screen-size aware, and add a first catalog of native adjustable Smart Shapes.

**Architecture:** Keep saved diagrams as ordinary Excalidraw scene JSON. Header and sharing changes stay in the app shell; zoom-aware insertion is an opt-in extension of the existing image insertion pipeline; Smart Shapes remain ordinary line polygons with versioned `customData`, generated by pure geometry functions and edited through a small action/handle layer.

**Tech Stack:** React 19, TypeScript, Excalidraw canvas/element packages, Vitest and Testing Library, Convex share mutations, SCSS, Cloudflare Workers.

Define:

```ts
export type ViewportInsertionRequest = {
  targetScreenSize: number;
  viewportFraction: number;
};

export const IMAGE_STUDIO_INSERTION: ViewportInsertionRequest = {
  targetScreenSize: 320,
  viewportFraction: 0.55,
};
```

`resolveViewportInsertion` must:

1. Compute usable pixel width and height after offsets.
2. Compute the target longest side as the minimum of 320px, 55% usable width, and 55% usable height after applying aspect ratio.
3. Divide pixel dimensions by zoom to return scene dimensions.
4. Return the usable viewport center in viewport coordinates.
5. Preserve the natural aspect ratio and reject non-finite/zero dimensions.

- [ ] **Step 3: Define versioned metadata and guards**

```ts
export type SmartShapeKind =
  | "filled-arrow"
  | "chevron"
  | "brace"
  | "bracket"
  | "parenthesis"
  | "callout";

export type SmartShapeMetadata = {
  version: 1;
  id: SmartShapeId;
  kind: SmartShapeKind;
  parameters: Record<string, number>;
};

export const getSmartShapeMetadata = (
  element: ExcalidrawElement,
): SmartShapeMetadata | null => {
  const value = element.customData?.yasinSmartShape;
  return value?.version === 1 && isSmartShapeId(value.id) ? value : null;
};
```

Invalid or unknown values return `null` without rewriting `customData`.

- [ ] **Step 4: Implement generators**

Use a canonical horizontal generator and transform points for direction:

```ts
const rightArrow = (
  width: number,
  height: number,
  p: FilledArrowParameters,
) => {
  const shaft = clamp(p.shaftRatio, 0.1, 0.9) * height;
  const headStart = width * (1 - clamp(p.headLengthRatio, 0.15, 0.75));
  const center = height / 2;
  return [
    [0, center - shaft / 2],
    [headStart, center - shaft / 2],
    [headStart, 0],
    [width, center],
    [headStart, height],
    [headStart, center + shaft / 2],
    [0, center + shaft / 2],
    [0, center - shaft / 2],
  ].map(([x, y]) => pointFrom<LocalPoint>(x, y));
};
```

Mirror or rotate the canonical points for left/up/down. Implement chevrons as closed seven-point polygons with a clamped `thicknessRatio`. Implement braces, brackets, and parentheses from the exact normalized point sets in `excalidraw-library-yasin`, scaling by width and height. Implement callouts as closed rectangle polygons with a clamped tail anchor/width; set rounded callouts' element roundness to type 2.

```ts
export type SmartShapeHandle = {
  name: SmartShapeHandleName;
  scenePoint: GlobalPoint;
};

export const getSmartShapeHandles = (
  element: ExcalidrawLinearElement,
): SmartShapeHandle[] => {
  const metadata = getSmartShapeMetadata(element);
  const definition = metadata
    ? getSmartShapeDefinition(metadata.id)
    : undefined;
  if (!metadata || !definition) {
    return [];
  }
  const center = pointFrom<GlobalPoint>(
    element.x + element.width / 2,
    element.y + element.height / 2,
  );
  return definition
    .getHandlePoints(element.width, element.height, metadata.parameters)
    .map(({ name, point }) => ({
      name,
      scenePoint: pointRotateRads(
        pointFrom<GlobalPoint>(element.x + point[0], element.y + point[1]),
        center,
        element.angle,
      ),
    }));
};

export const hitTestSmartShapeHandle = (
  element: ExcalidrawLinearElement,
  scenePoint: GlobalPoint,
  zoom: Zoom,
): SmartShapeHandleName | null =>
  getSmartShapeHandles(element).find(
    ({ scenePoint: handlePoint }) =>
      pointDistance(handlePoint, scenePoint) <= 8 / zoom.value,
  )?.name ?? null;
```
